# CardVault PWA

## Install on your phone
1. Upload this folder to a web host that provides HTTPS (GitHub Pages is a simple option).
2. Open the resulting CardVault web address on your phone.
3. iPhone/iPad: Share → Add to Home Screen.
4. Android/Chrome: menu → Install app / Add to Home screen.

The app includes a manifest and service worker for installability and offline shell caching. Your collection data is stored locally in the browser on the device.
